# Connected Mode — eRAN21.1 Feature Sheets

One Word-like Excel file. One sheet per feature chapter of *Mobility Management in Connected Mode* (Huawei eRAN21.1 Issue 08).

## File

Current version: **v2.0**

[Connected_Mode_eRAN21.1_Feature_Sheets_v2.0.xlsx](./Connected_Mode_eRAN21.1_Feature_Sheets_v2.0.xlsx)

## How to read

Open **00 Contents**, then **04 Basic Functions** (required for every later feature), then features 5–14 in order.

**Chapter 5:** read **5.1 Overview** first. It is shared by every coverage sub-group (5.2–5.6). It lists measurement-based, preferential blind, emergency blind, Event A2 families, and UTRAN/GERAN selection principles. Then open **5.3** (types in that sub-group, then Principle as numbered points).

Gridlines are off. Each feature sheet: Introduction (sub-groups) → Overview (types + major points) → Principle (numbered) → each sub-group → Combined summary → Parameter list.

Parameter list columns: SN | MO | Parameter | **Value** (value only, blue) | Comment | Core | Sub-group | **Parameter Meaning** | **Reference** (Feature ID + document name + section).

Hyperlinks: Contents, previous feature, next feature, Chapter 4.
