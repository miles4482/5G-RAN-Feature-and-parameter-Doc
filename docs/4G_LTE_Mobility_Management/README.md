# Connected Mode — eRAN21.1 Feature Sheets

One Word-like Excel file. One sheet per feature chapter of *Mobility Management in Connected Mode* (Huawei eRAN21.1 Issue 08).

## File

Current version: **v2.4**

[Connected_Mode_eRAN21.1_Feature_Sheets_v2.4.xlsx](./Connected_Mode_eRAN21.1_Feature_Sheets_v2.4.xlsx)

## How to read

Open **00 Contents**, then **04 Basic Functions**, then **Measurement Event** (Table 4-8 and entering/leaving charts for A1–A5, B1, B2), then features 5–14.

Every feature sheet now uses the same box style:

- **Common for sub-group** or **Overview of types** (boxed)
- **Principle** (numbered, boxed)
- Each sub-group, then Combined summary, then Parameter list

Gridlines are off. Thin black borders on boxes.

Parameter list: SN | MO | Parameter | **Value** (blue) | Comment | Core | Sub-group | **Parameter Meaning** | **Reference**.
