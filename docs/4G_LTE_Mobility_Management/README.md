# Connected Mode — eRAN21.1 Feature Sheets

One Word-like Excel file. One sheet per feature chapter of *Mobility Management in Connected Mode* (Huawei eRAN21.1 Issue 08).

## File

Current version: **v2.1**

[Connected_Mode_eRAN21.1_Feature_Sheets_v2.1.xlsx](./Connected_Mode_eRAN21.1_Feature_Sheets_v2.1.xlsx)

## How to read

Open **00 Contents**, then **04 Basic Functions** (required for every later feature), then features 5–14 in order.

**Chapter 5:** read **5.1 Common for sub-group** first (boxed). It is shared by every coverage sub-group (5.2–5.6). Measurement-based and Blind sit side by side; Event A2 and UTRAN/GERAN principles sit side by side. Then open **5.3** (boxed types + numbered Principle).

Gridlines are off. Boxed blocks use a thin black border.

Parameter list columns: SN | MO | Parameter | **Value** (value only, blue) | Comment | Core | Sub-group | **Parameter Meaning** | **Reference**.
